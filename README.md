# SkillBridge

DNSC's OJT placement decision support application: React/Vite frontend and
Django/DRF backend with PostgreSQL.

Start with [local setup and operations](knowledge/LOCAL_SETUP_AND_OPERATIONS.md)
and the [project overview](knowledge/PROJECT_OVERVIEW.md). Development status,
acceptance criteria and resume prompts live only in the
[continuous checklist](outputs/defense-review/SkillBridge_Continuous_Development.md).
Official LMS/IAMS compatibility and final local/hosted acceptance remain pending.

Use isolated synthetic data for checks. Existing configured secrets, student
records and hosted services are not test fixtures.
