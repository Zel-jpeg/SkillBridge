# SkillBridge coordinator evaluation checklist

Use a synthetic cohort first. Confirm which decisions the written assessment
informs, who reviews the results and who approves the placement before using
authorized program content. The Tourism coordinator described training, an
interview and then an exam. Confirm the role of that exam with the coordinator.
The Social Work report came from a student. Confirm partners, roles, the
paper-based assessment and placement steps with its coordinator.

## Prepare a session

- [ ] Record the program, evaluator role, date, test environment and build.
- [ ] Ask the coordinator to choose one realistic partner and opening and
  explain whether the seats are shared with other programs.
- [ ] Ask for a reviewed questionnaire sample, answer keys and the competencies
  it can assess. Use synthetic learner records or records approved for the session.
- [ ] Agree on expected answer totals and expected placement constraints before
  showing any results. Include an ineligible opening or a filled position.
- [ ] Set up a coordinator account, a student account and a program with a small
  framework. Keep the admin role available for assignment and shared catalog tasks.

## Observe the walkthrough

| Task | What to compare |
| --- | --- |
| Select the program and create a category with a description and tags. | The evaluator can explain what the category measures and reuse it in that program. |
| Create or reuse a partner and add an opening before enrollment. | The role, slot count, tags and numerical requirements agree with the scenario. |
| Create a batch, enroll a learner, import or enter questions, and publish. | The chosen format, question types, saved keys and category mappings match the reviewed sample. |
| Take the assessment and review the result. | Check the saved answers and raw and maximum scores against the agreed key. If multiple assessments are required, confirm that final results unlock after completion. |
| Review recommendations and approve a placement. | Check program and framework eligibility, the recorded score evidence and shared capacity. Record where an interview or training result would inform the coordinator's decision. |
| Export a report and review a denied or closed case. | Check filter scope, report counts, answer key access and what the coordinator sees when an opening closes. |

## Record findings

- [ ] Record what the evaluator completed, where they needed help and any
  observed workaround. Capture the role, screen, steps and expected and actual
  behavior for reproducible bugs.
- [ ] Record content feedback separately. Ask whether the categories,
  questions, keys and numerical requirements reflect the program's process.
- [ ] Record whether the eligible recommendations were relevant and why. Use
  independent cases and criteria for any claim about recommendation quality.
- [ ] Review the written assessment's limits with the evaluator. Practical
  proficiency calls for evidence from program-appropriate tasks.
- [ ] Check LMS import of a SkillBridge-generated AIKEN file in an authorized
  test question bank if LMS exchange is part of the session.
