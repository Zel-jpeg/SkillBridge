Data Dictionary

SkillBridge — Web-Based OJT Placement Decision Support System
Database: PostgreSQL (Supabase) Tables: 14 Schema Groups: 4 Version: 1.0

The Data Dictionary presents a detailed description of all data elements used in the proposed SkillBridge Web-Based OJT Placement Decision Support System, serving as a reference for the system's database structure and data organization. It defines the tables, fields, data types, constraints, and descriptions to ensure consistency, accuracy, and proper understanding of how data is stored and managed within the system.

This section is essential in guiding the implementation of the database and supporting system development, maintenance, and future enhancements.

The system database is organized into four (4) logical schema groups: User Management, Assessment Engine, Response & Scoring, and Placement Matching — comprising a total of 14 application tables stored in a PostgreSQL instance hosted on Supabase.

Table 1 provides an overview of all database tables utilized in the system. Subsequent tables (Table 1.1 through Table 1.14) present the detailed structure of each table, including field names, data types, field lengths, constraints, and descriptions.

Database Tables Overview
Table 1.  Database Tables of the SkillBridge System
# Table Name Schema Group Description
1 User User Management Stores account information, roles, and profile data for all system users (students, instructors, and administrators).
2 Batch User Management Represents instructor-managed student groups used to organize and assign assessments.
3 BatchEnrollment User Management Junction table linking students to their enrolled batches; enforces unique enrollment per student per batch.
4 SkillCategory Assessment Engine Defines skill taxonomy entries (e.g., Programming, Communication) used to categorize questions and score students.
5 Assessment Assessment Engine Stores assessments created by instructors, including title, duration, and batch assignment.
6 Question Assessment Engine Contains individual test questions belonging to an assessment, with type and skill category tags.
7 AnswerChoice Assessment Engine Holds answer options for MCQ and True/False questions, including the correct-answer flag.
8 StudentResponse Response & Scoring Tracks a student's overall submission record for an assessment, including start/submit timestamps.
9 ResponseAnswer Response & Scoring Stores each individual answer submitted by a student for a specific question within a response session.
10 SkillScore Response & Scoring Records the computed raw score, max score, and percentage per skill category per student per assessment.
11 Company Placement Matching Stores company profiles including name, geographic address, and GPS coordinates for OJT host matching.
12 Position Placement Matching Represents specific job positions offered by companies, along with the number of available slots.
13 PositionRequirement Placement Matching Defines the minimum skill percentage required per skill category for each position.
14 Recommendation Placement Matching Stores AI-generated cosine similarity match scores between a student's skill profile and a company position.

Table 1.9  ResponseAnswer

Table 1.10  SkillScore
Field NameData TypeField LengthConstraintDescription
idBIGINT8Primary KeyUnique skill score record identifier; auto-generated serial.
raw_scoreINTEGER4Not NullNumber of correct answers the student achieved within the given skill category.
max_scoreINTEGER4Not NullTotal number of questions in this skill category for the given assessment (maximum possible score).
percentageFLOAT88Not NullComputed proficiency percentage: (raw_score / max_score) × 100. Used as the student's skill vector component for cosine similarity matching.
student_idBIGINT8Foreign Key Not NullReferences User.id. Identifies the student whose score is recorded. ON DELETE CASCADE.
assessment_idBIGINT8Foreign Key Not NullReferences Assessment.id. Identifies the assessment from which this score was derived. ON DELETE CASCADE.
skill_category_idBIGINT8Foreign Key Not NullReferences SkillCategory.id. Identifies the skill category being measured. Unique together with student_id and assessment_id. ON DELETE CASCADE.

Table 1.13  PositionRequirement
Field NameData TypeField LengthConstraintDescription
idBIGINT8Primary KeyUnique position requirement record identifier; auto-generated serial.

Table 1.14  Recommendation
Field NameData TypeField LengthConstraintDescription
idBIGINT8Primary KeyUnique recommendation record identifier; auto-generated serial.
