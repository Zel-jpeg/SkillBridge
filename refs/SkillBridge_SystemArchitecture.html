System Architecture Discussion

The SkillBridge system follows a three-tier web-based architecture composed of the presentation layer, application layer, and data layer. The presentation layer consists of a React-based frontend application deployed through Vercel, which allows students, instructors, and administrators to interact with the system using desktop and mobile devices. Users access the system through secure HTTPS communication and authenticated REST API requests.

The application layer is composed of a Django REST Framework backend hosted on Railway.app. This layer handles business logic, authentication, assessment management, recommendation generation, and communication between the frontend and the database. The backend also contains the NLP-based recommendation engine implemented using scikit-learn and NumPy libraries. The recommendation engine processes assessment responses, computes skill scores, and applies cosine similarity matching to determine the most suitable OJT positions for students.

The data layer uses a PostgreSQL database hosted on Supabase for persistent data storage and retrieval. The database stores user records, assessments, responses, company information, positions, recommendations, and skill scores. External APIs such as Google OAuth, PSGC API, and Nominatim Geocoding API are integrated into the system to support authentication, address selection, and geographic location services.

Overall, the architecture ensures scalability, maintainability, secure communication, and efficient interaction among the system components.
